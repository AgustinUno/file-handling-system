## 📋 Overview

A console-based program that demonstrates core file I/O operations in C++. The program covers the three fundamental file handling modes: reading from a file, writing to a file, and appending data to an existing file.

> Built as a lab exam submission — not intended for production use.

---

## ✨ Features

- 📖 &nbsp;**Read** — Load and display data from a file
- ✏️ &nbsp;**Write** — Create and write data to a file
- ➕ &nbsp;**Append** — Add new data to an existing file without overwriting

## 🚀 Getting Started

### Prerequisites

- GCC / G++ compiler or any C++ IDE (e.g. Code::Blocks, Dev-C++, VS Code with C++ extension)

### Setup

**1. Clone the repository**
```bash
git clone https://github.com/AgustinUno/SETB--FILEHANDLING-SYSTEM.git
cd SETB--FILEHANDLING-SYSTEM
```

**2. Compile**
```bash
g++ "Set_B -Justine_Jul14.cpp" -o file-handling
```

**3. Run**
```bash
./file-handling
```
